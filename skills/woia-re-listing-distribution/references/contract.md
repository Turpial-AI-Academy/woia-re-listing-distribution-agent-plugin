# Channel publication contract

Permanent semantic source: `Turpial-AI-Academy/woia-re-domain-contracts-agent-plugin@v0.5.7`, commit `fb1c8a3f7fb116f2a00daf05ae335fdfbc7c3f3f`, tree `f3ff5a68a0d5df2e615a650eddc313c9585b7f08`. Its provider, domain-source, authority and E2E design references preserve ChannelPublication and Source Authority, exact approval binding and unknown-effect gates. Logical domain schemas remain owned by that plugin; this helper defines only its invocation envelope. This semantic reference adds no hard intra-wave repository dependency or runtime registry admission.

Actions: `channel-publication.create`, `channel-publication.sync`, `channel-publication.withdraw`, `channel-publication.status.observe`, `channel-publication.effect.reconcile`, `channel-publication.interaction.observe`.

The deterministic helper prepares an effect intent, records immutable remote observations and normalizes inbound interaction references. It performs no network dispatch. No portal adapter is advertised as qualified. A deployment must supply a separately qualified adapter and atomic durable compare-and-swap storage; a returned intent is not remote publication evidence.

The trusted caller resolves organization scope, current source map, granted action, department, principal, policy revision and clock. `context.grant` must bind the current principal, organization, exact publication, public-listing-distribution purpose, enumerated actions and active unrevoked validity window. `context.sourceBinding` must bind that publication/channel account to the effective source-map revision and its active unrevoked window. Missing/expired/future source rules and holds fail closed. Supply Acquisition may perform only scoped status observation, never effect reconciliation or inbound interaction normalization. Approval must come from a competent independent principal, resolve accepted authority outside model inference, bind the exact action/target/payload digest/revisions, be active and unrevoked. Technical access is insufficient authority. Unknown or concurrent pending effects block another mutation until reconciled; timeout never authorizes retry.

Create/sync require accepted current ListingVersion, exact content and media digests, effective Mandate and accepted rights/media rights. The caller must resolve those facts from accepted sourced Property Data and competent owners. Withdraw does not infer that Listing itself was withdrawn. Desired and observed remote state never rewrite canonical local Listing. Observations require configured channel source, immutable evidence reference, source revision, occurrence and freshness. Expired/future observations produce UNKNOWN.

Marketing exclusively owns effect preparation, reconciliation and channel interaction normalization. Customer Service may read explicitly scoped status and receives person inquiries/comments/messages as `communication.external.receive` handoff data via Communications; only that provider/department executes person ingress or responses. This helper never replies, pays, changes Listings or grants authority.

Persist each returned state atomically with expected revision; serialize concurrent effects per publication scope. Retain original evidence references outside prompts. Inputs are organization-private; public tests use synthetic values. Operator E2E and production qualification remain NOT_RUN.
